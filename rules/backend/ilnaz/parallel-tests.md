# Тесты с -n auto

**Когда применять:** при любом прогоне pytest.

**Правило:** использовать `-n auto` через pytest-xdist для параллельного запуска. Стандартный набор флагов — `-n auto -x -q`.

**Пример:**

```bash
docker compose exec app_metrica python3 -m pytest <path> -n auto -x -q
```

**Почему:** ускоряет прогон ~×2. `-x` — fail-fast (остановиться на первом падении), `-q` — короткий вывод.
