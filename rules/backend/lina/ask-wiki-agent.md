# Вопросы по документации — агенту wiki-research

**Когда применять:** любой вопрос «как решено по продукту»: поля, валидация, тексты, права, API, сценарии,
сверка кода с тех.спекой, разбор задачи MCA-XXX по документации. Например: «какая валидация у названия
отдела?».

**Правило:** по вики самому не искать — вызывать агента `wiki-research` (Agent, `subagent_type:
wiki-research`), передав вопрос, ключ задачи и ссылку на вики, если есть. Slug из памяти, старых заметок и
угаданные пути не использовать, `wiki_page_get` напрямую не звать. Ответ агента пересказывать с меткой у
каждого факта, `modified_at` рядом со ссылкой на страницу, не снимая пометку «с кодом не сверено».

Вопрос о поведении продукта без слов «в коде» / «как сейчас реализовано» сразу уходит агенту, без уточнений.
Код смотреть, только если о нём спросили прямо или попросили сверку; тогда сначала агент, потом код.

**Почему:** командный стандарт поиска — скилл `metrica-erp/standards/skills/wiki-research`; страницы вики
переезжают, а агент на Haiku держит обход дерева вне основной сессии.
