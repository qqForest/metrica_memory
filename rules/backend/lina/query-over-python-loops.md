# Запрос вместо циклов в Python

**Когда применять:** при работе с выборками из БД; такие упрощения предлагать, не дожидаясь замечания.

**Правило:** один запрос лучше питоновского цикла по выборке.

- «Есть ли объект вне множества» → `qs.exclude(pk__in=...).exists()`, не загрузка и фильтр в Python.
- Разница множеств → `qs.exclude(field__in=new_ids).exists()`, не `set(qs.values_list(...)) - new_ids`.
- Дифф «было/стало» — одним `values_list('id', 'field')` в dict, не хелпером с запросом на каждый элемент.
- Перед своей поштучной проверкой поискать готовый queryset-метод с нужной семантикой.

**Почему:** меньше запросов и кода, проверка читается по доменному смыслу. Источник: MCA-693.
