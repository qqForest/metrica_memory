# Данные на средах не готовить

**Когда применять:** новое поле с дефолтом «ломает» существующих пользователей (флаг `default=False`).

**Правило:** не предлагать data-миграцию для backfill, расширение админки и правку `create_superuser`. Один
раз назвать разрыв фактом («после накатки флаги пустые») и идти дальше. Тестовые фикстуры чинить
обязательно. Объём задачи — по тех-доку: модель, миграция схемы, код.

**Почему:** данные на средах при выкатке проставляет тимлид.
