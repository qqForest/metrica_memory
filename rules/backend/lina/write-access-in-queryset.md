# Доступ на запись — в get_queryset

**Когда применять:** нужно запретить редактировать или удалять часть объектов, которые пользователь видит.

**Правило:** проверка «можно ли вообще трогать объект» — в `get_queryset` для `update`/`partial_update`/`destroy`,
не в `Serializer.validate`. Недоступный объект выпадает из выборки → `get_object()` отдаёт 404. Сам фильтр — в
сервисе, эталон `UserService.get_editable_queryset` (`user_profiles/services/services.py`).

Проверки уровня полей (нельзя менять себе роль и т. п.) остаются в сериализаторе — они про поля, не про объект.

**Почему:** DELETE не проходит через сериализатор — проверка в `validate` оставляет дыру на удаление. Фильтр в
queryset закрывает PATCH и DELETE одним местом. Источник: ревью Руслана, MCA-692.
