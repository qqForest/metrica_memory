# Классы выше функций

**Когда применять:** при раскладке нового модуля или переносе кода.

**Правило:** в модуле сначала классы, функции уровня модуля — под ними. Python резолвит имена
при вызове, класс может ссылаться на функцию ниже.

«Спусти под класс» — переставить функцию ниже класса в файле, а не делать её методом.

Функция, которую зовут или будут звать из нескольких мест, остаётся функцией модуля. Функция с одним
вызовом, которая держит правило с ветвлением и именем, — `@staticmethod` в том классе, где её зовут.

**Почему:** класс — основная сущность модуля, с него начинается чтение. В MCA-898 проверку
наложений периодов спрятали в класс, и её пришлось доставать обратно для MCA-906.
