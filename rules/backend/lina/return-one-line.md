# return одной строкой

**Когда применять:** при любом `return`, который не влезает в строку.

**Правило:** `return` помещается на одной строке и заметен глазом. Склейку ФИО, тернарники, словари на
несколько ключей считать в переменных выше, возвращать короткое выражение. Многострочный `return {...}`
и тернарник с переносом через `\` не писать — вместо тернарника обычный `if`.

```python
username = user.username
full_name = f'{user.last_name} {user.first_name}'.strip()
return {'id': user.id, 'username': username, 'full_name': full_name}
```

**Почему:** когда `return` тянется на пять строк, точка выхода теряется среди остального кода.

Не противоречит [[literal-over-single-use-constant]]: там запрет на переменную ради укорачивания вызова,
здесь — на растягивание самого `return`.
