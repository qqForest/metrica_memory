# Связанные записи — в одной транзакции

**Когда применять:** при написании и ревью кода, где подряд идут несколько записей в БД.

**Правило:** несколько связанных write-операций (`create`/`save` + `.set()` на M2M, объект + лог,
родитель + дочерние) — в одном `with transaction.atomic():`. Где ставить — в сервисе, см. [[service-layer]].

```python
with transaction.atomic():
    schedule = Schedule.objects.create(**data)
    schedule.admins.set(admins)
    schedule.groups.set(groups)
```

**Почему:** падение на второй записи оставит полусозданный объект (расписание без админов).
