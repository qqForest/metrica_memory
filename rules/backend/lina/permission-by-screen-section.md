# Право вьюсета — по разделу экрана прав

**Когда применять:** выбор `permission_model` / `permission_code` / `permission_group` для эндпоинта.

**Правило:**

- Право определяет раздел макета экрана «Права доступа» в Figma, а не модель, от которой идёт выборка.
  Аналитический табель ходит от `WorkShift`, но живёт в разделе «Учёт времени» — закрыт `shifts.view_timeclock`.
- Разделы макета: Расписание, Учёт времени, Данные, Сотрудники, Настройки. Права вне CRUD — листья своей
  строки, а не отдельные строки.
- Узел дерева заводит та задача, которой право понадобилось первой. Код пути — `<раздел>.<модель во
  множественном>`: `schedule.shifts`, `timetracking.timeclocks`.
- Ресурс — часть другой сущности (настройки локации — часть карточки локации): закрывать правом родителя
  через `permission_code`, без своего `permission_group`. «На макете нет строки» само по себе не довод.
- Перед тем как закрыть чтение правом на запись — проверить во фронте, кто читает ручку (настройки локации
  читает мобильная отметка времени у рядового сотрудника).

**Почему:** право, выведенное из `queryset`, попадает не в тот раздел экрана, и владелец не найдёт галочку
там, где её ждёт. Сверку с макетом просил ревьюер.
