# Компактные строки — не дробить до 119 символов

**Правило:** выражение, которое помещается в **119 символов** (`backend/.flake8`), пишется в одну строку. Не
разносить `qs.filter(field1=val1, field2=val2)` или `datetime.combine(date, time, tzinfo=tz)` по аргументу на
строку.

Не влезает — без выравнивания по открывающей скобке: вынести часть в переменную выше или перенести аргументы
отступом 4, закрывающая скобка на своей строке (см. [[orm-query-style]]). `\` — только в импортах.

```python
# Плохо
notices.append(('open_shifts', ('Открытая смена: нужен сотрудник',
                                'Открытые смены: нужны сотрудники'), user_id, shift))

# Хорошо
titles = ('Открытая смена: нужен сотрудник', 'Открытые смены: нужны сотрудники')
notices.append(('open_shifts', titles, user_id, shift))
```

Logger-сообщения — короче, без «, пропускаем», «, продолжаем».

**Почему:** лишние переносы снижают плотность кода на экране; лимит в 119 уже даёт читаемость.
