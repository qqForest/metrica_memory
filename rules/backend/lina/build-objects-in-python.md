# Вложенный объект — в сериализаторе, не в SQL

**Когда применять:** в ответе нужен вложенный объект из связанной модели.

**Правило:** связанные поля тащить плоско через `values('fk__id', 'fk__name', ...)` и собирать объект в
сериализаторе: там же ветка «связи нет → null» и формат ФИО как в property модели. `JSONObject`/`Case` в
аннотации — только если по объекту дальше фильтруют или сортируют в БД.

Отдельный сигнал: Django не даёт назвать аннотацию, потому что имя занято полем модели. Это повод
пересмотреть подход, а не добавлять суффикс.

**Почему:** «нет второго запроса» обеспечивает и плоский `values()`; `JSONObject` на двадцать строк SQL там,
где хватает плоских полей, ревьюер вернул с вопросом «зачем».
