# Трекер: задачи, призывы, чек-листы, статусы

**Когда применять:** любая работа с очередью `MCA` в Яндекс Трекере.

**Правило:**

- **Задачи не заводить** и не предлагать «завести баг». Задачи заводит тестировщик (`arzamas.ufo`).
  Побочная находка — комментарием к текущей задаче для тестировщика: пусть проверит на стенде и заведёт сам.
  Созданную задачу нельзя удалить, только закрыть.
- **Никого не призывать** (`summonees`) без разрешения на этот конкретный комментарий; прошлое разрешение
  не переносится. Перед публикацией спросить «призвать кого-то?». Исключение: комментарий со ссылкой на PR
  из скилла `ship_pr` — всегда призывать тимлида.
- **Чек-листы задач эпика прав** писались под копирку: перед закрытием пройти построчно и сказать, какой
  пункт не закрывается и почему, предложить формулировку. Галочки и правку формулировок можно делать прямо в
  Трекере, но только после зелёного прогона. Пункт про дерево прав не про задачу, если вьюсет делит модель с
  уже переключённым; пункт «неаутентифицированный → 401» дописывать, раз тест всё равно пишется.
- **Статус задачи** брать из Трекера (`issue_get`), а не из заметок памяти: задачи переводят ревьюер и
  тестировщик, заметки отстают.
- Комментарии уходят от имени владельца токена MCP — черновик показывать и публиковать только по явному
  слову.

**Почему:** задачу и её комментарии читает вся команда, призыв шлёт уведомления, созданную задачу не
удалить — ошибки здесь необратимы.
