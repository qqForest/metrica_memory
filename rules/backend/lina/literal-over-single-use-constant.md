# Без лишней косвенности: литералы и значения по месту

**Когда применять:** перед тем как завести модульную константу под строку или число.

**Правило:** константу заводить, только если значение используется в 2+ местах или это публичный
контракт. Одноразовое значение — литералом по месту.

```python
# Плохо
RATELIMIT_LOGIN = 'login'
@ratelimit(RATELIMIT_LOGIN)

# Хорошо
@ratelimit('login')
```

**Почему:** константа нужна как единый источник правды при переиспользовании. При одном
использовании она не страхует от разъезда, а добавляет строку и импорт (решение Руслана).

## Без косвенности ради длины строки

Значение пишется прямо в вызове: `audit_logger.bulk_log(LogTypeChoices.ABSENCE, ...)`. Не влезает в 119 — перенести строку. Не заводить ради длины константу (`LOG_TYPE`), атрибут класса (`log_type`) или кортеж с распаковкой `*log_args`: соседние вызовы начинают выглядеть по-разному, а линтер не сверяет `*args` с сигнатурой (MCA-1005).

Словарь-конфигурацию в стороне от кода не заводить: две-три особенности — прямо в методы, где применяются; так их проще удалить.
