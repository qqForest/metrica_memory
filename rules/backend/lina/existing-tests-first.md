# Сначала существующие тесты

**Когда применять:** баг нашёлся, особенно если он прятался за неверными тестовыми фикстурами.

**Правило:** сначала починить фикстуры и прогнать существующие тесты модуля без фикса в коде — часто они
сами падают и уже покрывают регрессию. Новое писать только на непокрытое, ассертом в существующий тест, а
не отдельным файлом или классом.

**Почему:** однажды отдельный файл из двух тестов оказался лишним — после правки `conftest` регрессию
ловил уже существующий тест, непокрытым был один сценарий. Лишние кейсы — прямое время пайплайна.
