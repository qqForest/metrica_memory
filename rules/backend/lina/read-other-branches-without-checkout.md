# Чужую ветку читать без checkout

**Когда применять:** ревью чужого PR, сверка с `development` или любой другой веткой в `backend`.

**Правило:** читать через `git show <ref>:<путь>` и `git diff origin/a...origin/b`. Команды, которые меняют
HEAD, индекс или рабочее дерево (`checkout`, `switch`, `stash`, `reset`), без явной просьбы не запускать.
Если чтения не хватает (нужен прогон тестов на чужой ветке) — сначала спросить.

**Почему:** в рабочем дереве почти всегда своя ветка с незакоммиченными правками. Переключение ломает
состояние, которого Claude не видит, а для чтения файлов оно не нужно.
