# Код под снос не трогать

**Когда применять:** правка сделала старый код недостижимым или мёртвым.

**Правило:** если на этот код уже есть задача сноса, код и форму ответа оставить как есть. Удалить только
тесты, которые из-за правки падают, потому что проверяют исчезнувшее поведение. Перед попутной чисткой
проверить, нет ли такой задачи.

**Почему:** пустое поле ничего не ломает, а удаление — лишние правки и лишнее изменение контракта для фронта.
