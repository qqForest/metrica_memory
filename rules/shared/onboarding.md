# Онбординг — синхронизация скиллов

**Когда применять:** когда кто-то подключает metrica_memory впервые, или явно просит проверить скиллы.

---

## Правило

1. Прочитай `skills/backend/<имя>/` в репо — что там есть.
2. Прочитай `~/.claude/skills/` и `.claude/commands/` локально — что уже подключено.
3. Сравни. Для каждого недостающего предложи команду для симлинка или копии.
4. Для каждого лишнего (есть локально, нет в репо) — предложи добавить в репо, если может пригодиться коллеге.

---

## Пример вывода

```
В репо есть, локально нет:
→ get_desc: ln -s ~/Projects/metrica_memory/skills/backend/lina/get_desc ~/.claude/skills/get_desc

Уже подключено: ничего
```

---

## Почему

Правила подключаются через `CLAUDE.md` автоматически — скиллы нет. При первой настройке легко пропустить. Явная сверка в начале экономит время и не даёт скиллам коллег лежать мёртвым грузом в репо.
