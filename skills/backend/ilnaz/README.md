# skills/backend/ilnaz/

Личные скиллы Ильназа. Можно подсматривать и копировать. Если что-то реально полезное — кидаем в `skills/shared/` через PR.

## Что тут есть

<!-- по мере добавления — обновляй список -->

- [`task/`](task/SKILL.md) — `/task`, детали задачи в Яндекс Трекере: заголовок, статус, описание, исполнитель, последние комментарии и ссылка.
- [`default-pipeline/`](default-pipeline/SKILL.md) — `/default-pipeline`, разведка перед стартом задачи Metrica: контекст из Трекера, кода, соседних PR и `metrica_memory` → вопросы и согласование скоупа (код не пишем).

## Как добавить

```bash
mkdir <skill-name>
$EDITOR <skill-name>/SKILL.md
```

Минимальный `SKILL.md`:

```markdown
---
name: skill-name
description: Одна строка — что делает.
---

# Что и как делать (на русском).
```
