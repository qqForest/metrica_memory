# /task — Детали задачи

Показывает подробную информацию о конкретной задаче в Яндекс Трекере.

## Аргументы

- `$ARGUMENTS` — ключ задачи (например: `MCA-45`). Если пользователь указал только число (например `45`), подставь префикс `MCA-`.

## Инструкция

1. Используй `issue_get` с `issue_id` = ключ задачи, `include_description` = true
2. Используй `issue_get_comments` для получения комментариев
3. Выведи:
   - **Заголовок** и статус
   - **Описание** (если есть)
   - **Исполнитель**, приоритет, дедлайн
   - **Последние комментарии** (до 5 штук, с авторами и датами)
4. Покажи URL задачи через `issue_get_url`
