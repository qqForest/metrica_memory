# Как добавлять в metrica_memory

Стартуем минималистично: легче добавлять, чем разгребать. Несколько правил, чтобы не превратить репо в свалку.

## Куда что класть

### `shared/` — общекомандное

Сюда переезжает то, что **полезно всем** в команде. Пример: формат коммитов, правила сдачи PR, скилл для разбора тикетов техподдержки.

**Критерий:** если коллега подключит этот скилл/правило без правок и оно сразу будет работать — это `shared/`.

### `backend/<имя>/` — личное, но «открытое»

Это твоя личная папка. Сюда кладёшь то, что:
- работает у тебя, но коллеге может не подойти без правок,
- ты пока обкатываешь и не уверен, что обобщать,
- сугубо твой workflow, но коллега может подсмотреть.

**Не стесняйся.** Лучше положить «грязноватое» в `<имя>/`, чем потерять. Потом, если коллега скажет «о, удобно», переедет в `shared/`.

### Никогда не в репо

- Секреты, токены, креды → `~/.claude/settings.local.json` или `.env`
- Чужие данные клиентов
- Внутренние ссылки, которые могут утечь публично, если репо когда-нибудь станет открытым

## Формат

### Скилл

Один скилл = одна папка `<skill-name>/` с файлом `SKILL.md` внутри. Минимальный шаблон:

```markdown
---
name: skill-name
description: Одна строка, что делает скилл. Используется Claude'ом для выбора.
---

# Тело скилла на русском.
# Что делать пошагово.
```

Подробности про формат — в [Claude Code docs / Skills](https://code.claude.com/docs/en/skills).

### Правило

Один файл `.md` на тему. Короткие, конкретные. Если правило больше экрана — скорее всего, его надо разбить.

Структура:
```markdown
# Название правила

**Когда применять:** …

**Правило:** …

**Почему:** …  ← важно, чтобы будущий-ты мог судить пограничные случаи
```

## Процесс

1. Создал в своей папке (`backend/<имя>/`) — коммит, push, готово.
2. Если думаешь, что в `shared/` — открывай PR, обсудим в комментариях.
3. PR в `shared/` принимает второй человек из команды. Само-мерж только в свою папку.

## Удаление

Если правило/скилл больше не актуально:
- из `shared/` — удалять через PR с пояснением, **почему** больше не нужно (на будущее, чтобы не вернулось);
- из `<имя>/` — удаляй как хочешь, это твоя территория.
